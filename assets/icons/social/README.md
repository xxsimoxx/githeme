# Social menu SVG assets

Individual icons from **Font Awesome Free 7.1.0**, by Fonticons, Inc.

- Source: <https://github.com/FortAwesome/Font-Awesome/tree/7.1.0/svgs>
- Original paths: `svgs/brands/<name>.svg`; `envelope`, `phone`, and `location-dot` use `svgs/solid/`.
- Icons are licensed under **CC BY 4.0**: <https://creativecommons.org/licenses/by/4.0/>.
- The upstream distribution license is preserved in [LICENSE.txt](LICENSE.txt), and each SVG retains its original attribution comment.
- Changes: explicit 24 × 24 dimensions, a theme CSS class, `currentColor`, and decorative accessibility attributes on the SVG root. Original path artwork and view boxes are unchanged.

Only SVG icons are bundled here, without Font Awesome fonts, JavaScript, CSS, or runtime dependencies. Brand names and logos remain trademarks of their respective owners; their inclusion does not imply endorsement.

Google Maps links use the generic Font Awesome `location-dot`. No Google trademark artwork is bundled: a suitably redistributable official asset was not established. Reference reviewed: <https://about.google/brand-resource-center/products-and-services/geo-guidelines/>.
