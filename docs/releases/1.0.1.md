# GiTheme 1.0.1

GiTheme 1.0.1 is a maintenance release improving navigation, pagination and gallery presentation.

- Make numbered pagination consistent across category and other archives, search results, post listings and comments. Single posts use compact, translated Previous/Next buttons with the same styling.
- Display Gallery Slider captions as readable overlays inside their images, with responsive typography and native scrolling for long text. Image sizing and keyboard navigation are preserved.
- Apply navigation dropdown styling before JavaScript initializes, preventing expanded submenus from briefly appearing in the page flow. Preserve responsive enhancement and a usable CSS-only fallback.

Minimum requirements remain **ClassicPress 2.7** and **PHP 8.2**.
