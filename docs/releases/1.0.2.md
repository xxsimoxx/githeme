# GiTheme 1.0.2

GiTheme 1.0.2 is a maintenance release improving keyboard-focus indicator contrast in header navigation and dropdown menus.

- Automatically select a contrasting focus color when the configured primary color falls below the 3:1 contrast threshold. Preserve the primary focus color when contrast is sufficient.
- Evaluate header and dropdown backgrounds independently so focus indicators remain visible on each surface.
- Preserve existing navigation behavior, hover styling and theme customization options.

Minimum requirements remain **ClassicPress 2.7** and **PHP 8.2**.
