# GiTheme 1.0.0

GiTheme 1.0.0 is the first stable release of a lightweight, general-purpose classic theme for ClassicPress. It combines native CMS features, responsive layouts and progressive enhancement without a frontend framework, a required build step or mandatory plugins.

## Highlights

- Customize colors, locally hosted typography, content widths, header arrangement, logo, site title and tagline through the native Customizer. Header and footer backgrounds are independently configurable, with informational contrast feedback.
- Use responsive navigation with keyboard access, visible focus and a usable no-JavaScript fallback.
- Build a static homepage with optional Homepage Hero and Homepage Content widget areas, alongside normal page content. Add optional footer widgets and control page-title visibility individually.
- Display category archives as responsive article cards with featured images, category labels, native excerpts and pagination.
- Enhance native galleries with `[gallery layout="slider" ids="12,34,56"]`: proportional images, native scrolling, previous/next controls, keyboard focus enhancement, reduced-motion support and no autoplay.
- Add the native **GiTheme – Featured Posts** and **GiTheme – Gallery Slider** widgets without requiring a builder plugin.
- Keep Classic Editor typography consistent with the frontend. Optional integrations include wide FX Builder rows and theme-aware styling for FX Shortcodes Button, Card, Cover, Details and Separator components.
- Use the original US English interface or British English, Italian, German and Dutch localization.

## Requirements and installation

- **ClassicPress 2.7 or later** and **PHP 8.2 or later**.
- PHP’s **DOM extension** is needed for gallery slider enhancement; without it, galleries retain native rendering.
- Download the installable `githeme-1.0.0.zip` release asset and upload it through **Appearance → Themes**. No additional plugin is required.

GiTheme is accessibility-minded, with semantic markup and progressive enhancement; this is not a claim of WCAG certification. Site content, color choices and third-party plugins also affect accessibility.
